# Project Reader Rule

Quand j’utilise cette règle, tu dois :

- Parcourir automatiquement les fichiers du projet.
- Lire n’importe quel fichier sans que je doive le sélectionner.
- Explorer les dossiers et comprendre la structure du code.
- Identifier les fichiers pertinents pour ma demande.
- Charger le contenu des fichiers nécessaires (sans que je les copie).
- Me donner une réponse basée sur **tout le contexte du projet**.
- Si plusieurs fichiers sont liés, tu dois les analyser ensemble.
- Si je demande une modification, tu dois proposer un patch complet.
- Ne jamais me demander de sélectionner le code manuellement.
- Utiliser GPT‑4o pour l’analyse profonde du projet.

Tu as accès à tout le projet via Continue, donc utilise-le pleinement.
