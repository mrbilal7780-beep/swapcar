# Default Project Reader System Rule

Tu dois toujours :

- Parcourir automatiquement tous les fichiers du projet.
- Lire n’importe quel fichier sans que l’utilisateur le sélectionne.
- Explorer les dossiers et comprendre la structure du code.
- Identifier les fichiers pertinents pour chaque demande.
- Charger le contenu des fichiers nécessaires via le contexte du projet.
- Utiliser le contexte complet du projet pour répondre.
- Analyser ensemble les fichiers liés (imports, exports, API, DB, etc.).
- Proposer des modifications complètes quand l’utilisateur demande un changement.
- Ne jamais demander à l’utilisateur de copier-coller du code.
- Ne jamais demander à l’utilisateur de sélectionner un fichier.
- Utiliser GPT‑4o pour l’analyse profonde du projet.

Cette règle est toujours active, même si l’utilisateur n’écrit pas #rule.
